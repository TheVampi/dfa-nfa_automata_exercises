# Languages and Automata I - Exercise Repository

Welcome! This repository contains a collection of solutions to various problems from the Languages and Automata I course. 

Each exercise is documented in detail, including its description, sample strings, the automaton's formal definition, its diagram, and the corresponding JFLAP file.

## Course Information
This project was developed as part of the curriculum at the **Tecnológico Nacional de México en Celaya**.
* **Degree:** B.S. in Computer Systems Engineering
* **Course:** SCD-1015 Languages and Automata I
* **Professor:** Ing. Luis Gerardo López Ruiz

## Contents

This project covers the following topics:
- Design of Deterministic Finite Automata (DFA)
- Design of Non-deterministic Finite Automata (NFA)
- Recognition of languages defined by regular expressions
- Application of the Chomsky Hierarchy
